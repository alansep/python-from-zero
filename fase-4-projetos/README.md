# Fase 4 — Transição para Desenvolvedor (Projetos Práticos)

> ⏱️ **~18h** · 🚧 **Estrutura planejada** — os projetos serão criados em breve.
> Acompanhe o progresso no [README raiz](../README.md).

**Meta:** consolidar a lógica construindo projetos completos **sem depender do autocompletar da IA**.

| # | Projeto | O que consolida | Tempo |
|---|---|---|---|
| 1 | **Simulador bancário** | Regras de negócio, validações, loops de menu, saída formatada | 5h |
| 2 | **Gerenciador de cadastro** | Dicionários + persistência em `.json`/`.csv` em disco | 6h |
| 3 | **Analisador de logs** | Leitura de arquivos, filtragem e geração de relatório | 6h |
| 4 | **Revisão final** | Refatoração, comentários e checklist "pronto para a fase de libs" | 1h |

## Regras dos projetos

1. Ler o enunciado e **planejar no papel** (entradas, saídas, regras) antes de codar.
2. Não existe gabarito — planeje, code e valide pelo próprio `enunciado.md` e pela validação.
3. Errou? Leia o erro no terminal **antes** de chamar a IA.
4. Cada projeto termina com um checklist de aceitação (como um teste de verdade).
