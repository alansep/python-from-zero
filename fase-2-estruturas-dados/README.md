# Fase 2 — Estruturas de Dados e Manipulação

> ⏱️ **~10h** · 🚧 **Estrutura planejada** — os exercícios serão criados em breve.
> Acompanhe o progresso no [README raiz](../README.md).

**Meta:** aprender a organizar e manipular coleções de dados na memória.

| # | Tópico | Conteúdo | Tempo |
|---|---|---|---|
| 1 | **Listas** | Indexação, fatiamento (*slicing*), mutabilidade e métodos (`append`, `pop`, `remove`, `sort`, `len`) | 4h |
| 2 | **Tuplas e Conjuntos** | Imutabilidade de dados e remoção de duplicatas | 1.5h |
| 3 | **Dicionários** | Mapeamento chave-valor, busca eficiente e objetos aninhados | 2h |
| 4 | **Strings** | Interpolação (f-strings) e métodos (`split`, `join`, `strip`, `replace`) | 1.5h |
| 5 | **Compreensão de listas** | *List comprehension* — a sintaxe mais pythonica da linguagem | 1h |

Cada tópico terá o mesmo formato da Fase 1: `enunciado.md` + `atividade.py` + `checar.py` (sem gabarito — o esforço é parte do estudo).
