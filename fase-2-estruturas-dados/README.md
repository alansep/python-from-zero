# Fase 2 — Estruturas de Dados e Manipulação

> ⏱️ **~10h** · 5 tópicos, 37 exercícios no total
> Acompanhe o progresso no [README raiz](../README.md).

**Meta:** aprender a organizar e manipular coleções de dados na memória.

| # | Tópico | Conteúdo | Tempo |
|---|---|---|---|
| 1 | **[Listas](./01-listas/)** | Indexação, fatiamento (*slicing*), mutabilidade e métodos (`append`, `pop`, `remove`, `sort`, `len`) | 4h |
| 2 | **[Tuplas e Conjuntos](./02-tuplas-conjuntos/)** | Imutabilidade de dados e remoção de duplicatas | 1.5h |
| 3 | **[Dicionários](./03-dicionarios/)** | Mapeamento chave-valor, busca eficiente e objetos aninhados | 2h |
| 4 | **[Strings](./04-strings/)** | Interpolação (f-strings) e métodos (`split`, `join`, `strip`, `replace`) | 1.5h |
| 5 | **[Compreensão de listas](./05-compreensao-listas/)** | *List comprehension* — a sintaxe mais pythonica da linguagem | 1h |

Cada tópico segue o mesmo formato da Fase 1: `enunciado.md` (teoria + exercícios) + `atividade.py` (você edita) + `checar.py` (validação automática).

```bash
python3 fase-2-estruturas-dados/01-listas/atividade.py
```
